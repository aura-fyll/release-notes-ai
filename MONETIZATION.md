# Monetization — How the Money Works

## TL;DR

- **Free tier:** Generates a short AI summary (~120 words) on every GitHub release. No payment. Users bring their own OpenRouter key. Limited to last 25 commits, English, professional tone, with "Generated by Release Notes AI" footer.
- **Pro tier ($9/month or $79/year):** Full structured release notes (Features / Bugs / Docs / Refactor / Perf), all languages, custom tones, full commit history, premium LLM model, and auto-broadcast to Slack/Discord/Email/Twitter via Composio. No branding.
- **Payments:** Polar.sh handles everything (cards, Apple/Google Pay). 4% + $0.40 per transaction. Zero monthly cost. Native license keys.
- **Your cost:** $0/month until ~50 Pro users. Then ~$29/mo for Composio Pro.

---

## Why the Free Tier Is Nerfed (Conversion Strategy)

A useful-but-limited free tier converts better than either:
- (a) a fully-featured free tier (no reason to upgrade), or
- (b) a useless free tier (no reason to install in the first place).

We use the **"taste then crave"** pattern:

| Limit | Why it works |
|---|---|
| Short summary only (120 words) | Users see the AI is good → want the full structured version |
| Last 25 commits only | Anyone with a real release hits this immediately |
| English only | ~40% of GitHub devs are non-English — instant upgrade trigger |
| Locked tone | Casual OSS maintainers want "casual" — friction triggers upgrade |
| Budget LLM model | Quality gap is *visible* — Pro feels faster and smarter |
| "Generated by Release Notes AI" footer | Two effects: (1) drives installs from people who see it on others' releases, (2) annoys serious maintainers into upgrading to remove it |
| No broadcast | This is the *flagship* Pro feature — visible in every Pro demo |

### Conversion math

Industry baseline for self-serve dev tools: **3% free → paid conversion**. With the limits above, we aim for **4–5%**. Levers:

- Visible "Generated by Release Notes AI" footer drives install virality (free growth)
- Quality gap (budget vs Claude 3.5 Sonnet) creates upgrade desire
- Commit limit creates hard friction after ~2 releases
- Multi-language is a sharp upgrade trigger for non-English OSS (large untapped market)

## Why $9/month (not $5, not $19)?

- **$5** feels too cheap — users assume it's low quality.
- **$19** is too high for a single-feature tool — users hesitate.
- **$9** is the "no-brainer" price for solo maintainers and small teams. It's less than a single Slack paid seat, and it saves them 30+ minutes per release.

Annual discount: **$79/year** (save ~27%). Push annual hard — it locks in revenue and reduces churn.

## Revenue Levers (in priority order)

1. **Raise conversion rate** — every 1% = ~25% more revenue. The free-tier limits above are the main lever.
2. **Add annual plan** — locks in users, improves cash flow. ~30% of Pro users will pick annual.
3. **Add a $29/mo "Team" tier** — multi-repo dashboard, shared Slack webhook, custom prompts, priority support. ~10% of Pro users upgrade.
4. **Affiliate program** — give OSS influencers 30% commission for referrals. Polar supports this natively.
5. **Enterprise licensing** — once you have 100+ Pro users, pitch companies with private GitHub Enterprise. Custom pricing ($500–$5,000/year).

## Anti-Piracy Notes

- Polar license keys are unique per customer. They CAN be shared — accept this as minor leakage.
- The Action validates on every run, so a cancelled subscription stops working within ~30 days.
- Don't bother with DRM for a $9 dev tool — the goodwill from being chill about it pays back in referrals.
