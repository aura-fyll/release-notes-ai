## Why?

Every maintainer hates writing release notes. Conventional-commits autogeneration is robotic and unreadable. Hand-writing them takes 30+ minutes per release and never feels right.

**Release Notes AI** generates clean, human-readable release notes from your commit history and merged PRs the moment you publish a release.

## Install (Free Tier)

1. Click **"Use this Action"** on the Marketplace listing.
2. Add this workflow to your repo at `.github/workflows/release-notes-ai.yml`:

```yaml
name: 'Release Notes AI'
on:
  release:
    types: [published]
permissions:
  contents: write
  pull-requests: read
jobs:
  generate-notes:
    runs-on: ubuntu-latest
    steps:
      - uses: aura-fyll/release-notes-ai@v1
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          openrouter_api_key: ${{ secrets.OPENROUTER_API_KEY }}
```

3. Get a free OpenRouter API key at https://openrouter.ai/keys
4. Add it as a repo secret named `OPENROUTER_API_KEY` (Settings → Secrets and variables → Actions → New repository secret).
5. Publish a release — done. Summary appears within ~30 seconds.

**That's it. Free forever.** Runs on GitHub's free Actions minutes for public repos.

## How it works

1. On `release: published`, the Action fetches commits and merged PRs since the previous release.
2. **Free:** Trims to last 25 commits / 10 PRs, sends a short-summary prompt to a budget LLM.
   **Pro:** Sends the full history with a structured-notes prompt to Claude 3.5 Sonnet.
3. The Action updates the release body with the new notes.
4. (Pro only) Validates the Polar license, then posts to connected channels via Composio.

---

## Privacy

- Commit messages and PR titles are sent to OpenRouter for processing. No source code is sent.
- License keys are validated against Polar's API. We never store them.
- For private repos, GitHub's encrypted secrets are used end-to-end.
